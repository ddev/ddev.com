Quick reference for using the DDEV name and logo. For the full brand guide, additional PNG resolutions, and the logo-generation script, see the <a href={BRAND_GUIDE_URL}>Brand Guide</a> in the DDEV documentation.

## Naming

- **DDEV** — the project name, always capitalized.
- **ddev** — lowercase, only when referring to the command-line binary itself (for example, `ddev start`).
